# Triage labels

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | More reporter or installation evidence is required. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for an agent. |
| `ready-for-human` | `ready-for-human` | Requires physical, artistic, rights, or safety judgment. |
| `wontfix` | `wontfix` | Will not be actioned. |
